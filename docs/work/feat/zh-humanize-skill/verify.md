### 輸入（逐字）

```
【樣本 A · 外部合成文本，已知含 AI 味】
這場工作坊不僅標誌著我們社群經營邁入全新階段，更見證了學習型社群的無限可能，為未來的每一步奠定了堅實的基礎。

【樣本 B · docs/index.html hero 副標】
它本來就很會寫 code。麻煩的是同一句「改一下這裡」，它今天直接動手，明天卻先問你三個問題。bstack 是一份把這件事釘住的設定檔——28 個 skill、6 個 agent、2 個 PreToolUse hook，加上一份誰都繞不過的規則書，同步進 ~/.claude/ 就生效。

【樣本 C · docs/index.html 三個 beat 段落】
C1: 每個請求進來先跑 Phase 0：讀 memory、看 codebase、估影響檔、判是修 bug 還是做功能、判量體落在 T0 到 T3 哪一級。判完把三件事併成一張選單問你——而且是選項不是自由回答。
C2: 碰到前端檔會先查這塊屬於哪一套設計語言、把實際的色碼與字級抄出來，抽不到就說抽不到。沿用既有 token 的小改直接做完再對四項檢查；新頁或改版屬於大改，會先出三個差異化方向、附真實視覺讓你挑，選定才落 code。
C3: 寫測試 → 跑到它紅 → 寫最小實作 → 跑到它綠 → commit。途中如果冒出計畫裡沒寫到的前端檔，它會停下來重新判定該區塊的設計語言，而不是順手改一改當作沒發生過。
```

### 三處**沒有**報的，這是本次最有價值的證據

| 沒報的東西 | 理由 |
|---|---|
| 「一份誰都繞不過的規則書」 | 這是**事實宣稱過度**，屬事實查核。`SKILL.md` 的 `不要觸發` 明列「事實查核（非風格問題）」。**主 session 先前用別的視角批評過這句，但那不是本 skill 的職責**——它守住了自己的邊界 |
| C1 的「是選項不是自由回答」 | 形式近 `#12`，但該節明文「這個句型本身沒有錯⋯處理原則不是看到就砍」，且 C1 無價值升級詞、順序相反。**誤殺邊界，放行** |
| C2、C3 整段 | 無命中 |

**三段獨立真實文本裡兩段完全放行**，只有破折號格式。這是「不亂改」那一半的證據。

### 一個實跑才發現的邊界問題

`#23` 的密度規則是「每 300–500 字最多 1 次」。樣本 B 約 110 字用 1 次、C1 約 90 字用 1 次——**按段計超標，按整頁計未必**。報出來的依據是**格式**（前後無半形空格）那半，密度那半取決於邊界怎麼畫。`scenes.md` 沒有定義「一份稿」的邊界，這是自寫層的一個缺口。

### 情境層的第一個實測缺口

樣本 A 落在五個情境**之外**，而 auto 路徑不能問。目前的處置是「標註後按最輕處理」，但 `scenes.md` 沒有明文規定這種情況該怎麼辦——它只寫了「判不出來就問使用者」，那條在 auto 路徑上不成立。

## 已知限制

1. **自寫層沒有回歸網。** `scenes.md`、`examples.md`、`protected-list.md` 的新增節共約 8KB，`benchmark.md` 的 42 條用例全是上游情境，量不到它們。改動這三處時**沒有任何自動檢查會發現改壞了**。
2. **V7 的正向樣本來自訓練集。** 樣本 A 取自 `benchmark.md` 的 SF-01，屬上游用來調規則的用例。它證明機制跑得動、輸出形狀正確，**不證明對沒見過的文本的泛化能力**。真正獨立的是樣本 B、C（本 repo 自己的頁面），而那兩份的結果是「幾乎全放行」。
3. **「一份稿」的邊界未定義**（見 ③ 的密度問題）。
4. **auto 路徑遇到情境判不出來時沒有明文規則**（見 ③）。
5. **`CLAUDE.md §Task 追蹤` 在本次施工全程無法執行。** `TaskCreate` / `TaskUpdate` 在 Claude Code v2.1.233+ 的 Claude 5 家族模型上預設不提供（官方 [tools-reference](https://code.claude.com/docs/en/tools-reference) 明載），需 `CLAUDE_CODE_ENABLE_TODO_TOOLS=1`。本機 `settings.json` 的 `permissions.allow` 列了那四個工具，**但那是授權清單不是啟用開關**，實際未生效。十個 task 全程用 plan 的 checkbox 與逐 task 回報替代。
6. **`docs/reference/docs-site-baseline.md` 有一條過期**：「既有缺口 4」寫 `@media` 0 命中、零響應式，改版後實測是 2。不在本 branch scope。
7. **`docs/js/references-data.js` 仍缺兩個 skill**，且產出器不在 repo。merge 後 repo 28 skill、docs 站文件抽屜 27。
