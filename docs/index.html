bstack

一套 Claude Code 的設定檔集合：27 個 skill、6 個 agent、2 個 PreToolUse hook， 加上一份 CLAUDE.md 規則書。裝法是把檔案同步到 ~/.claude/，不經過 marketplace。

開啟流程圖→ 安裝步驟
01

這是什麼

Claude Code 讀 ~/.claude/ 底下的 skill、agent、hook 與 CLAUDE.md 來決定怎麼工作。 bstack 就是這幾類檔案的一份具體內容。

它做的事是把「寫 / 改 / 修 / 加 / 重構」這類請求導進一條固定的九階段流程， 並依改動量體決定該跑多嚴：一行 typo 直接做；跨模組或動到 DB schema 的改動， 要先寫 spec、寫實作計畫、四個視角 review、跑 TDD 紅綠循環、做安全稽核，最後另外落一份 PR 詳解。

它是為單一使用者的日常開發習慣寫的，公開出來是因為結構本身可以被抄走改成自己的。 沒有版本相容性保證，也沒有安裝以外的支援。

02

內容清單

裝進 ~/.claude/ 的東西，全部在這裡：

  • skills27 主流程 12 條、跨流程觸發式 9 條、meta 4 條、設計 lane 2 條
  • agents6 review / 安全稽核 / e2e / 假設驗證跑獨立 context，避免重 tool 噪音與球員兼裁判
  • hooks2 branch-safety.ps1 擋 protected branch 寫入；file-type-guard.ps1 按檔案類型分流
  • CLAUDE.md1 九條強制守則、Tier 機制、commit 與 branch 規範；優先於任何 skill
  • 其他3 settings.json（merge 安裝，本機值優先）、statusline.sh、scripts/setup.ps1
03

九階段

Dev track 的完整順序。Bug track 走 debug-systematic 取代第 2、3 階段，其餘相同。 Tier 決定哪幾階段會被跳過。

  • 01brainstorm
  • 02write-plan
  • 03execute-plan
  • 04verify-done
  • 05request-review
  • 06security-audit
  • 07finish-branch
  • 08pr-explain
  • 09retro

每輪回覆結尾會貼一行 [Trace] Phase=… | Tier=… | Track=… | Skill=…， 用途是讓「現在跑到哪、為什麼跑這條」隨時可查，而不是事後回想。

04

Tier 決定嚴格度

量體在 brainstorm 階段判定，並用 AskUserQuestion 跟使用者確認過才算數。

Tier量體會跑什麼
T01 行 / typo / 設定值全跳，直接做
T1≤2 檔 / 單模組小改對話釐清、1–2 個關鍵測試、self review
T23–10 檔 / 單模組 feature完整 spec 與計畫、Eng 視角 review、TDD 紅綠循環、subagent review
T3>10 檔 / 跨模組 / DB schema再加四視角 plan review、雙視角 code review、安全稽核與 checklist
05

強制守則

這九條優先於任何 skill，衝突時以它們為準。

  • 事實核實　下結論前並行驗「儲存的實際內容」與「codebase 使用點」，缺一不可。
  • Task 追蹤　任務開始前先建 task，狀態隨進度更新。
  • 決策點選單　使用者的決策一律走 AskUserQuestion；禁止把「好」「OK」這類文字當成通過的信號。
  • Branch safety　PreToolUse hook 直接擋掉對 main / master / production 的寫入。
  • File-type 硬規則　密鑰禁 commit；migration、lockfile、CI、infra 各有對應處置。
  • PII 安全底線　個資原值禁止落到對話、log 或 commit，輸出一律遮蔽或彙總。
  • DB 操作　讀走唯讀 MCP，寫的部分產出 SQL 交由使用者執行。
  • 設計語言對齊　動前端檔之前先讀該區塊既有的設計語言，從實際檔案抄值，不憑印象重畫。
  • Docs 落檔　流程產出的文件按壽命分目錄，不按文件類型分。
06

安裝

需要 git、jq（statusline 用）、Node.js 與 npx（兩個 MCP 用）。 setup 會直接覆蓋 ~/.claude/ 裡的同名檔案且不備份，先自己備份再跑。

  1. 取得 repo
    git clone https://github.com/fujiei22/bstack.git
cd bstack
  2. 同步到 ~/.claude/

    settings.json 走 merge 而非覆蓋，permissions.* 以本機既有值為準。

    pwsh -File scripts/setup.ps1
  3. 裝兩個 MCP

    mysql MCP 的三個寫入開關都設 false，並建議搭配唯讀權限的 DB user 做雙保險。

    # 依 db-access skill 的唯讀政策，寫入一律關閉
claude mcp add mysql --scope user \
  --env MYSQL_HOST=127.0.0.1 --env MYSQL_PORT=3306 \
  --env MYSQL_USER=<readonly-user> --env MYSQL_PASS=<password> \
  --env ALLOW_INSERT_OPERATION=false \
  --env ALLOW_UPDATE_OPERATION=false \
  --env ALLOW_DELETE_OPERATION=false \
  -- npx -y @benborla29/mcp-server-mysql

claude mcp add playwright --scope user \
  -- npx -y @playwright/mcp@latest
  4. 開新 session

    既有的 Claude Code session 不會載入新裝的 skill，要開新的才生效。
